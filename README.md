# Улучшенный PiP для Chrome

Компактный Picture-in-Picture с удобным управлением видео: перемотка, громкость по наведению, избранные скорости и перетаскивание окна за видео.

## Quick start — быстрый запуск

1. Открой [последний релиз](https://github.com/xtalia/independent-pip/releases/latest), скачай **`independent-pip-…-unpacked.zip`** и распакуй в постоянную папку. Сборка не нужна; `manifest.json` должен лежать прямо в выбранной папке.
2. В Chrome открой `chrome://extensions` и включи **Режим разработчика**.
3. Нажми **Загрузить распакованное расширение** и выбери эту папку. При желании закрепи **Independent PiP** через значок пазла.
4. Запусти видео на сайте и нажми значок расширения или **Alt+Shift+P**. Повторное нажатие закрывает PiP. Если играющего видео нет, появится список для выбора.

Для поиска видео на других вкладках нажми **Разрешить поиск на вкладках** в окне выбора и подтверди доступ. Это необязательно: без разрешения доступны видео текущей вкладки.

Уже установлено? Обновляй файлы **в прежней папке**, затем нажми **Reload** в `chrome://extensions` и обнови страницу с видео — [подробнее об обновлении](#обновление). Если используешь исходники репозитория, выбирай папку **`extension`**, а не корень репозитория.

## Установка — одна постоянная папка
Основной формат — **распакованное расширение**: все рабочие файлы лежат в одной папке, `manifest.json` — непосредственно в ней. ZIP для ежедневной работы не нужен.

1. При клонировании репозитория используй папку **`extension`**. Либо скопируй её содержимое в свою постоянную папку `independent-pip`. Не удаляй и не перемещай выбранную папку после установки.
2. Открой `chrome://extensions`.
3. Включи **Режим разработчика**.
4. Нажми **Загрузить распакованное расширение** и выбери папку, в которой лежит `manifest.json`.
5. При желании закрепи **Independent PiP** через значок пазла в Chrome.

## Обновление
Закрой старое окно PiP. Обнови файлы **в той же постоянной папке**, из которой установлено расширение (например, через `git pull`, если используется `extension` репозитория). В `chrome://extensions` нажми **Обновить / Reload** на карточке Independent PiP, затем обнови страницу с видео. На карточке должна быть версия **1.5.0**. Старое окно выбора после обновления закрой и открой заново.

Если переходишь на другую папку, Chrome создаст другой ID распакованного расширения: настройки могут не перенестись. После проверки новой копии отключи/удали старую, чтобы не конфликтовала горячая клавиша. Браузерный профиль автоматически не изменяется.

## Возможности
- Компактный тёмный интерфейс: видео заполняет содержимое окна, тонкая шкала перемотки, время по центру, кнопки без больших текстовых рамок.
- Наведение на заголовок показывает полное название в стандартной подсказке Chrome. Наведение на timeline показывает время под курсором, не меняя позицию видео; у краёв подсказка остаётся внутри окна. Время и скорость выровнены по центру одной строки со значками, в том числе в компактном окне.
- Клик по видео переключает play/pause без сброса позиции.
- По умолчанию скорости **0.5, 1, 1.10, 1.15, 1.25, 1.5, 2×**. В меню **⋮** остаётся точный ввод любой скорости 0.25–4×: `1.234` либо `1,234`, затем Enter/✓. Исходная нестандартная скорость добавляется в список, а не сбрасывается.
- В **⋮ → ⚙ Настройки** можно переключить избранный/расширенный список, выбрать шаг 0.05/0.1/0.25/0.5, добавить свои скорости, показать/скрыть кнопки **⏪ / ⏩** и включить автоскрытие. Изменения применяются сразу. Timeline и keyboard seek остаются при скрытых кнопках.
- Наведи на **🔊 / 🔇**: рядом появится ползунок. Если до центрального времени не хватает места, ползунок вертикальный над кнопкой. Доступен также через Tab; Escape закрывает popup. Slider изменяет исходное видео, ненулевая громкость снимает mute, mute после нуля возвращает последнюю ненулевую громкость.
- Зажми левую кнопку на видео и тяни: переносится **окно**, а не картинка. Порог 4px отделяет drag от клика; отпускание после drag не ставит паузу. Короткий клик по-прежнему play/pause. Controls не перетаскивают окно. При недоступной/неоднозначной привязке tooltip видео предлагает перенос за рамку Chrome.
- Перемещение синхронизировано с кадрами PiP-окна, без прежней задержки 32 мс. При задержке ответа Chrome промежуточные координаты заменяются последними, а не накапливаются в очереди; конечная позиция сохраняется. Это не меняет скорость воспроизведения видео и не гарантирует фиксированный FPS на каждом компьютере.
- Пользовательские скорости/нестандартный шаг из 1.1 сохраняются как расширенный режим. Старые стандартные настройки переходят на избранные. **Сбросить** возвращает новые defaults, не меняя скорость самого видео.
- Автоскрытие **по умолчанию выключено**. При включении панели исчезают через 3 секунды бездействия только во время воспроизведения. Движение мыши/клавиатура показывают их; пауза, keyboard focus, удержание мыши и открытое меню сохраняют видимость.
- Изменения настроек сохраняются локально. Их сохранность проверена после полного перезапуска выделенного Chrome.

## Использование
- Открой страницу и запусти HTML5-видео.
- Нажми значок расширения или **Alt+Shift+P**. Повторное нажатие закрывает PiP.
- **ПКМ на значке расширения → Настройки** открывает настройки; **→ Выбор видео** открывает список, даже если видео уже играет. Само открытие списка не закрывает работающий PiP.
- Если на текущей вкладке играет поддерживаемое видео — открывается оно (при нескольких — более крупное).
- Если играющего поддерживаемого видео нет, открывается **выбор видео**: играющие видео других вкладок первыми, затем видео на паузе. В списке видны название вкладки, сайт, статус и размер видео. Выбор видео на паузе сам его не запускает. Если в выбранной вкладке уже есть PiP другого видео, окно заменяется; устаревший выбор не закрывает работающее окно.
- Для поиска по другим вкладкам один раз нажми **Разрешить поиск на вкладках** и подтверди доступ к HTTP/HTTPS-сайтам в Chrome. Это дополнительное разрешение: без него доступны только видео исходной вкладки. Для повторного поиска есть **Обновить список**; закрытые/изменившиеся видео нужно выбрать заново.
- Зависшая вкладка больше не задерживает весь список: поиск ограничен по времени, а неполный результат помечается как частичный. Если service worker остановился во время поиска, запрос списка повторяется один раз. Открытие видео автоматически не повторяется — команда могла уже выполниться.
- Выбор доступен и с вкладок без видео, с неподдерживаемым плеером или со служебных страниц Chrome. Неподдерживаемое видео не преобразуется: предлагаются доступные HTML5-видео на других вкладках.
- **▶ / ⏸** — воспроизведение/пауза, **⏪ / ⏩** — ±10 секунд, **🔊 / 🔇** — mute и hover-громкость, **↩** — вернуться во вкладку, **✕** — закрыть. Точная скорость — в **⋮**. Подсказки и aria-label сохраняются; рисунок Unicode/emoji зависит от ОС и шрифта.
- В PiP, когда фокус не находится на кнопке/поле: **Space** — пауза, **←/→** — ±10 секунд, **Shift+←/→** — ±30 секунд, **M** — звук, **Esc** — закрыть.
- На кнопке play Space работает как обычное нажатие, без двойного переключения. В открытом меню Esc сначала закрывает меню. В текстовых полях shortcuts плеера не перехватываются.
- Если Chrome не назначил горячую клавишу из-за конфликта, задай её в `chrome://extensions/shortcuts`. Системное назначение hotkey не проверялось автоматическим тестом.
- Если на значке появился `!`, наведи мышь: подсказка содержит причину ошибки.

## Как это работает
Исходный video остаётся в DOM страницы и сохраняет свой playback pipeline. `captureStream()` передаёт видео-only поток в отдельное окно **Document Picture-in-Picture**; зеркало всегда muted. Кнопки управляют исходным video, а не отдельно загруженной копией URL.

При недоступности захвата/Document PiP расширение пытается открыть **стандартный video PiP Chrome**. В этом режиме дополнительные controls и субтитры расширения недоступны; подсказка значка сообщает о нативном режиме.

## Ограничения
- Расширенный режим рассчитан на desktop Chrome с Document PiP и secure context: HTTPS либо localhost. Минимальная версия в manifest — 116; фактические API определяются во время запуска.
- Стилизуется содержимое PiP, не системная рамка и строка источника Chrome.
- Поддерживаются обычный DOM, открытые Shadow DOM и same-origin iframe. Закрытый Shadow DOM и cross-origin iframe не читаются. Для cross-origin iframe открой исходную страницу плеера отдельно.
- Запуск — значком расширения или горячей клавишей; автоматическое открытие при переключении вкладки отсутствует. Доступ к другим HTTP/HTTPS-вкладкам — только после отдельного разрешения; поиск запускается открытием/обновлением списка.
- Настоящий DRM-сервис не тестировался. Расширение не обходит DRM, `disablePictureInPicture` или Permissions-Policy; нативный fallback тоже может быть запрещён.
- Активные стандартные TextTrack/VTT cues с mode `showing` по-прежнему выводятся автоматически, если включены в исходном плеере. Произвольные DOM-субтитры YouTube/сайтов не переносятся. Кнопка **CC** временно убрана: она не включала субтитры сайта, а только скрывала/показывала уже доступный стандартный текст. Полноценная поддержка — в TODO.
- При исчезновении исходного video или смене src окно закрывается. После смены плеера нажми значок снова.
- Canvas-видео без HTMLVideoElement не поддерживается.
- Исходный элемент не переносится, но `captureStream()` может требовать дополнительные ресурсы GPU/CPU. Производительность на каждом сайте не измерялась.

## Проверка
В изолированном Chrome 157 прошли **64 реальных browser integration tests** и **17 Node unit tests** модулей/транспорта. Проверяются PiP и decoded MP4/MSE/blob, неизменность исходного DOM и playback, controls/cleanup/reopen, выбор/замена видео и устаревшие UUID, native fallback, iframe/Shadow DOM/VTT, клавиатура, настройки и перезапуск браузера, компактный UI и очереди drag. Для picker воспроизведены замороженная вкладка и точная ошибка закрытия message channel при остановке service worker; исправления проверены на реальном Chrome. Для ПКМ проверены регистрация native menu и реальные эффекты callbacks, но не физический клик по меню Windows.

Итог и SHA-256 — в `docs/verification-v1.5.json`; raw-отчёты — в исключённой из Git папке `reports/`. GitHub Actions проверяет unit tests, синтаксис всех JS-модулей, manifest и соответствие runtime проверенным SHA-256 — это не повторный запуск browser integration suite. Границы модулей и правила для агента — в [AGENTS.md](AGENTS.md), карта потоков — в [архитектуре](docs/architecture.md).

Основная регрессия — **headless**, с настоящими pointer/keyboard событиями, native bounds readback и полным stop/restart service worker. Дополнительно API перемещения настоящего topmost PiP проверен в отдельном **headed** Chrome со скрытыми принадлежащими тесту окнами. Screenshots horizontal/vertical slider и compact overlay сняты и просмотрены. Физическая мышь/визуальная плавность/поведение поверх произвольных Windows-приложений, global hotkey, DRM и все production-сайты вручную не проверялись. Обычный профиль Chrome тестами не менялся. Нативное окно Chrome подтверждения/отказа дополнительного доступа в headless не автоматизировано: проверены реальные состояния с выданным доступом, без доступа и после его отзыва.

## Приватность
Обязательные разрешения: `activeTab`, `scripting`, `storage`, `contextMenus`. Последнее нужно для пунктов ПКМ только на значке расширения; меню сайтов не изменяется. Дополнительный доступ `http://*/*` и `https://*/*` запрашивается только кнопкой в окне выбора; его можно отозвать в настройках расширения Chrome. Без него другие вкладки не сканируются. Настройки — локально; служебная привязка только собственного PiP — временно в `storage.session`, чтобы пережить сон worker. Перенос проверяет инициировавшую вкладку, child tab, новый window ID и внутренний ISOLATED идентификатор. Не двигает родительские/посторонние окна. Нет обязательного доступа `<all_urls>`, сетевых запросов, сервера, аналитики, cookies, debugger, Native Messaging и внешних зависимостей.
